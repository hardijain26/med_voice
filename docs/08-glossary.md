# 08 — Glossary

Plain-language definitions of terms you may encounter around Med-Voice. If a term isn't here, it probably isn't essential to understanding the product.

| Term | Plain-language meaning |
|---|---|
| **OCR (Optical Character Recognition)** | Technology that "reads" text from a photo. It's how Med-Voice understands a label from a picture instead of you typing it. |
| **AI / Gemini** | The artificial-intelligence service that looks at the label photo, understands it, and rewrites the instructions. Gemini is the specific AI provider used. |
| **Text-to-speech (TTS)** | Technology that reads text aloud in a spoken voice. It's how Med-Voice *talks* to the user. |
| **Transliteration (phonetic text)** | Writing a language using another alphabet's letters so it can be pronounced correctly — e.g. writing Hindi words in English letters so the phone's voice says them right. |
| **Dosage** | How much of a medicine to take (e.g. one 500mg tablet) and how often. |
| **Meal-based timing** | Dose times tied to everyday moments — "after breakfast," "after dinner" — instead of abstract clock-only instructions. |
| **Fallback** | A safety net. When the AI can't respond, the app shows safe, pre-prepared guidance instead of an error. |
| **Webhook** | An optional connection that lets Med-Voice hand a request over to a partner's own system (e.g. a pharmacy's back-end) instead of processing it directly. |
| **Adherence** | Whether a patient actually takes their medicine correctly and consistently. Improving adherence is the product's ultimate purpose. |
| **Persona** | A short, realistic profile of a typical user (like "Kamala, 72") used to keep product decisions grounded in real needs. |
| **North-star metric** | The single most important number that captures whether the product is succeeding. |
| **Activation** | The moment a new user first gets real value — here, hearing their first clear spoken instruction. |
| **Permissions (camera/microphone)** | The access the app asks for from the phone. Camera is needed to photograph the label; microphone supports voice interaction. |
