## The 30-second version

Millions of seniors take the wrong dose, miss doses, or stop their medication simply because a prescription label is too small, too clinical, or in a language they don't read comfortably. Med-Voice fixes that in three taps:

1. **Point the camera** at the prescription label.
2. **Med-Voice reads it** using AI and rewrites the instructions in warm, everyday language.
3. **It speaks the instructions aloud** in the user's chosen language and sets **voice reminders** for each dose.

It supports **11 languages** today (including Hindi, Tamil, Bengali, Telugu, Marathi, Gujarati, Kannada, Malayalam, Punjabi, Spanish, and English) and is designed so that even when the internet or AI is having a bad day, the user still gets safe, usable guidance.
